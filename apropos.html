Développeur front-end depuis 2008, basé à Lyon. J’interviens sur tous types de projets, quelle que soit la technologie ou le CMS utilisé.

DN
Le profil

Né dans le multimédia, forgé dans l’intégration.

Mon cœur de métier, l’intégration web. Je veille à produire des composants responsives, accessibles et performants, en parfaite cohésion avec les spécifications fonctionnelles et techniques.

Je travaille en étroite collaboration avec les UI/UX pour mettre en place les micro-interactions, animations et transitions qu’ils imaginent.

Banque, assurance, grande consommation, e-commerce à fort trafic, applications mobiles : j’ai traversé des secteurs très variés, avec toujours un très bon relationnel, côté équipes projet comme côté clients.

Aujourd’hui, je travaille aussi avec l’IA générative, notamment Claude Code en mode vibe coding : je cadre, je pilote, je relis. Ce portfolio a été construit de cette façon.
