Les chroniques

Développeur front-end depuis douze ans (factices), je construis des interfaces où la performance et la mise en scène ne se font jamais la guerre.

DN
L'origine

Né dans le code, forgé dans le motion.

Tout a commencé avec un jeu vidéo : une transition de salle si parfaite qu'elle m'a fait comprendre qu'une interface pouvait raconter une histoire.

Depuis, je traque les millisecondes perdues, les easings paresseux et les états oubliés. Je travaille main dans la main avec les designers pour que chaque intention survive au passage en production.

Quand je ne code pas, je relance une partie de Hades « juste pour une run », j'explore le château des Belmont, ou je décortique les sites primés d'Awwwards image par image.
